# FFmpeg runtime

Visupra7 uses the bundled `ffmpeg.exe` as a separate process to encode webcam frames as H.264 MP4.

- Version: FFmpeg 4.2.1, Win32 static GPL build
- Source release: https://github.com/advancedfx/ffmpeg.zeranoe.com-builds-mirror/releases/tag/20200915
- Asset: `ffmpeg-4.2.1-win32-static.zip`
- Executable SHA-256: `E79D9B4BD7B0420B974EB58EB15D6F072EE939F98ACC93314A4CC750C6B7099D`
- License: GNU General Public License version 3 or later, as reported by `ffmpeg -version`

The corresponding FFmpeg source code is available from the source release and from https://ffmpeg.org/releases/ffmpeg-4.2.1.tar.xz.
